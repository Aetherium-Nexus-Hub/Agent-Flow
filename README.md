# Agent-Flow: AgendaFlow

**Description:** Transform any document into a structured, time-stamped meeting agenda and stakeholder map using AI.

## Overview

Agent-Flow, also known as AgendaFlow, is an innovative application designed to streamline meeting preparation and management. By leveraging artificial intelligence, it converts unstructured documents into organized, time-stamped agendas and provides a comprehensive stakeholder map, enhancing meeting efficiency and clarity.

## Features

*   **Document-to-Agenda Conversion:** Automatically generate structured meeting agendas from various document formats.
*   **Time-Stamped Agendas:** Each agenda item is precisely time-stamped for better time management during meetings.
*   **Stakeholder Mapping:** Identify and map key stakeholders relevant to the meeting, facilitating targeted communication and engagement.
*   **AI-Powered Insights:** Utilize AI to extract crucial information and create actionable meeting plans.

## Getting Started

### Prerequisites

*   Node.js

### Local Development

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Configure API Key:** Set your `GEMINI_API_KEY` in the `.env.local` file.
3.  **Run the application:**
    ```bash
    npm run dev
    ```
